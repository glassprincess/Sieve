# Sieve

Минимальный сканер памяти для Windows.

First Scan / Next Scan, сортировка по значению, правка и заморозка из списка.

## Запуск

Взять `sieve.exe` из Releases. Запускать желательно от администратора,
иначе чужая память может не открыться.

## Как пользоваться

1. Найти процесс через поиск слева, кликнуть.
2. Выбрать тип (I32 / I64 / Float / Double), ввести значение, First Scan.
3. Изменить значение в игре, выбрать фильтр, Next Scan. Повторять,
   пока не останется несколько адресов.
4. Клик по строке: Записать — поменять значение, Зафиксировать — держать.

Кнопка «Значение A-Z» сортирует список.

## Сборка

Нужен Rust stable и Windows 10/11.

```
cargo build --release
```

Иконка exe вшивается через `rc.exe` из Windows SDK.
Если его нет — соберётся без иконки, на работу не влияет.

## Предупреждение

Только в образовательных целях или если понимаешь, что делаешь.

- Используй в песочнице, тестах и локальных играх без античита.
  В онлайне и под EasyAntiCheat / BattlEye / Vanguard можно словить
  бан, вплоть до бана железа: там драйверы ядра, которые видят
  подобные инструменты (функционал уровня Cheat Engine).
- Запись в память может крашить игру и портить сейвы. Бэкапь сейвы.
- Антивирусы часто помечают такие программы как HackTool. Это ожидаемо,
  но файл проверяй сам, прежде чем добавлять в исключения.
- Не цепляйся к системным процессам и чужому софту.
- За баны и сломанные сейвы отвечаешь ты сам.
